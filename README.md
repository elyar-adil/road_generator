# 路口工坊 · Intersection Studio

一个完全运行在浏览器中的程序化三维路口设计工具。项目由原始的
`intersection_generator.html` 原型扩展而来，保留了道路、路沿、车道线、导向箭头、
信号灯、护栏、建筑和树木的生成能力，并加入了完整的项目工作流。

## 功能

- 2–8 个道路分支，可分别设置角度、进出车道、中央分隔和护栏
- 五种拓扑预设、随机生成和可复现的场景种子
- 3D 透视与正交俯视两种视图
- 可开关的车道级拓扑中心线叠加（3D 与俯视均可见），按直行/左转/右转着色
- 可开关的「分流/合流演示」图层，演示 3→2→3 走廊、人行道与路灯的复用抽象
- 交通信号动画、速度控制和暂停
- 可按进口道配置单/双左转弧形待转区或直行待行区标线
- 右转设施支持既有最右侧车道直接连接、近端分流右转车道、远端分流右转辅路（Slip lane）；分流/辅路的三角区域可选绿化岛或导流线区
- 可配置路口核心尺寸；默认按紧凑型城市路口的 30–42 m 三角分布生成
- 浏览器自动保存、撤销/重做、参数校验与实时统计
- 项目 JSON 导入/导出、PNG 截图、GLB 三维模型导出
- 响应式桌面/移动端界面
- 纯本地 Three.js 依赖，不依赖 CDN

## 开发

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址（默认 `http://127.0.0.1:5173`）。

## 构建与测试

```bash
npm test
npm run build
npm run preview
```

生产文件生成在 `dist/`。由于项目使用 ES 模块，开发版本和构建版本都应通过 HTTP
服务器访问，不建议直接双击 `index.html`。

## 项目结构

```text
intersection-generator/
├─ index.html             应用界面与无障碍结构
├─ src/
│  ├─ main.js             Three.js 场景、几何生成与交互
│  ├─ project-store.js    自动保存、下载与历史记录
│  ├─ state.js            项目模型、校验、统计与序列化
│  ├─ geometry.js         共享 2D 向量/曲线/虚线/offset/fillet 原语（全项目唯一来源）
│  ├─ segment.js          道路段复用抽象：车道束横断面、分流/合流渐变、人行道边界、路灯布点
│  ├─ lane-topology.js    显式车道级拓扑图（进/出车道与转向连接），驱动拓扑叠加与分流/合流
│  ├─ road-movements.js   转向分类与车道转向分配
│  ├─ right-turn.js       右转/分流/汇流设施的纯几何生成器
│  ├─ waiting-area.js     左转/直行待转区几何（复用 geometry.js）
│  ├─ state.test.js       状态层单元测试
│  └─ styles.css          响应式视觉系统
├─ package.json
└─ vite.config.js
```

车道级拓扑（lane graph）与道路段（segment）抽象是本项目的通用地基：分流/合流
渐变、人行道、路灯都建立在同一套可复用原语之上，可继续向立交桥/匝道等任意道路
类型扩展。

## 项目文件

“保存项目”会下载带格式名和版本号的 JSON 文件。导入时会校验文件类型、版本、道路数量、
车道范围和分支最小夹角。浏览器中的自动保存仅保留最近状态；需要长期归档时请导出 JSON。

GLB 导出包含当前生成的道路与场景对象，不包含编辑器界面和地面背景。
